# rust-template-hooks-actions
шаблон rust проекта с предустановленными git хуками и action


## 🪝  Pre-commit хуки (hk)

В проекте используется hk для управления pre-commit хуками.

Установка hk

Инструкция по установке:

### [ссылка на доку](https://hk.jdx.dev/getting_started.html)

установка hk глобально

```zsh
cargo install hk
```

установить cli для работы с pkl
```zsh
brew install pkl
```
